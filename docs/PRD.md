| PRD Section | Project Details |
| :--- | :--- |
| **Project Name** | Project 2: Restaurant Table Reservation System |
| **Team** | Team Pants |
| **Problem Statement** | Manual reservations via phone or other channels consume staff time and increase the risk of errors. |
| **Objective (Solution)** | A web-based application enabling customers to check available times, book, edit, and cancel reservations independently. |
| **Target Audience** | Restaurant customers and restaurant administrators/staff. |
| **Tech Stack** | React (Frontend), Java Spring Boot (Backend), PostgreSQL (Database), and Render (Deployment). |
| **Functional Requirements (FR)** | View restaurant details, view available times, make a table reservation, modify a reservation, cancel a reservation, and receive email confirmations. |
| **Non-Functional Requirements (NFR)** | Responsive web application (mobile-first), adequate color contrast, clear navigation, and easy-to-use forms. |
| **Out of Scope / Future Ideas** | Support for multiple restaurants, map views, user accounts/authentication, reviews, and reminder emails. |

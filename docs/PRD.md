| :--- | :--- |
| **Project Name** | Project 2: Restaurant Table Reservation System[cite: 14] |
| **Team** | Team Pants[cite: 14] |
| **Problem Statement** | Manual reservations via phone or other channels consume staff time and increase the risk of errors[cite: 14]. |
| **Objective (Solution)** | A web-based application enabling customers to check available times, book, edit, and cancel reservations independently[cite: 14]. |
| **Target Audience** | Restaurant customers and restaurant administrators/staff[cite: 14]. |
| **Tech Stack** | React (Frontend), Java Spring Boot (Backend), PostgreSQL (Database), and Render (Deployment)[cite: 14]. |
| **Functional Requirements (FR)** | View restaurant details, view available times, make a table reservation, modify a reservation, cancel a reservation, and receive email confirmations[cite: 14]. |
| **Non-Functional Requirements (NFR)** | Responsive web application (mobile-first), adequate color contrast, clear navigation, and easy-to-use forms[cite: 14]. |
| **Out of Scope / Future Ideas** | Support for multiple restaurants, map views, user accounts/authentication, reviews, and reminder emails[cite: 14]. |
